# Feature <a name = "Feature"></a>
- layout responsive
- menu bar Global turns into toogle menu (responsive)
- Cadastro de tarefas
- Histórico de tarefas de dias anteriores
- Global State Manager with Pinia
- Gerenciamento de Backlog: Organização e priorização de tarefas com controle de tempo de permanência e registro de impedimentos.
- Painel Fazendo Hoje: Visualização clara das atividades focadas no dia atual e acompanhamento das entregas concluídas no ciclo corrente.
- Relatório Feito Ontem: Histórico imutável e auditável das tarefas finalizadas em datas anteriores.
- Cadastro & Reutilização de Tarefas: Criação de novos cards ou reaproveitamento de tarefas existentes com geração automática de novas instâncias (IDs únicos) para preservação do histórico.
- Alertas Personalizados: Mensagens de aviso e notificação por tela totalmente configuráveis.
- Persistência de Dados: Sincronização automática de todas as operações no local Storage
- Padronização de Commits & Versionamento: Validação de commits via hooks de Git e automação de release com geração de histórico de alterações (Changelog).

# Technologies <a name = "Technologies"></a>
In 'Easy Tutorials' this project was developed with HTML, CSS language and a small block of JavaScript embedded in the HTML Code.

- Frontend Framework: Vue.js 3 (Composition API & <script setup>)
- State Management: Pinia
- Build Tool & Bundler: Vite
- Routing: Vue Router
- Styling: CSS3 (Scoped Styles / Flexbox)
- Code Quality & Commit Standard: Commitlint, Husky, Commitzen, Standard-Version

### Built With 
- Vue 3 - Framework JavaScript progressivo para construção de interfaces.
- Pinia - Store oficial e reativa para gerenciamento de estado global no Vue.
- Vite - Build tool de alta performance para desenvolvimento frontend moderno.
- JavaScript (ES6+) - Lógica reativa, manipulação de imutabilidade e persistência em Web Storage.
- Commitzen - Interface CLI para guiar a escrita de commits padronizados (Conventional Commits).
- Commitlint - Validador de mensagens de commit para garantir o padrão definido no projeto.
- Husky - Gerenciador de Git Hooks para disparar o commitlint antes do salvamento dos commits.
- Standard-Version - Ferramenta para automação de versionamento semântico (SemVer) e atualização de CHANGELOG.md.
